## 2. Принятые решения

| Тема | Решение |
|---|---|
| Гостиная | Неоклассика — **вариант 2 «бакинская»** (референсы `07_referensy/gostinaya/variant_2.jpg`): светлые стены с тонкой лепниной-рамками, простая светлая мебель, мало декора. Стены — **светло-серые, NCS S 1500-N** (пересогласовано под зелёную мебель; было NCS S 1002-Y), шторы **тёмно-зелёные**, моющаяся краска, молдинги в тон. **Лепнина (согласовано):** рамки с профилем ~70×24 и лепными уголками-акант во всех углах (референс `07_referensy/gostinaya/moldingi_3.jpg`, вариант 3, фото справа). **Без люстры** (решение заказчика): свет **(согласовано 11.2026, без треков)**: скрытый LED по периметру у карниза + белая световая рамка в потолке (линейный профиль заподлицо, 0,6 м от стен, 500 лм/м, ровность 0,76); **без бра** (убраны по решению заказчика); 2 канала диммера (рамка / периметр), 4 сценария: ночь ~35 лк, вечер ~170, обычный ~270, максимум ~370 (норма 150). Расчёт: `02_skripty/raschet/svet_gostinaya.py`. **Потолок (согласовано, образцы 1+5 `07_referensy/gostinaya/neoklassika_potolki_6.jpg`):** по эскизу заказчика — лепная рамка у стен (двойная линия) с узорами в 4 углах, световая рамка в центре (0,95 м от стен), по 3 круглых спота Ø100 вдоль длинных сторон между ними, **короб ГКЛ 340×100 по периметру (у окна — ниша штор), LED-лента за бортиком короба светит на центральный потолок +2700** (схема `07_referensy/gostinaya/potolok_razrez_kak_foto1.png`). Пол — **доска, палубная укладка (вразбежку)**, планки одного размера поперёк комнаты (параллельно окну), **2 тона через раз — беленый дуб «почти как стены»** (вариант 1, `07_referensy/gostinaya/pol_tona_3_pary.jpg`); **этот пол — во всей квартире, кроме кухни и мокрых зон**; живые образцы — подобрать в магазине, сверить с выкрасом стены. **Мебель (согласовано):** **диван — существующий у заказчика** (зелёный бархат, спинка с вертикальной стёжкой «каналами»; размер уточнить, на плане 2400) у стены напротив ТВ + 2 **«ушастых» кресла (wingback)** в бархате цвета дивана — по образцу №8 из `07_referensy/gostinaya/kresla_katalog_1.jpg` (стёжка пуговицами, отогнутые подлокотники, конические ножки) (`07_referensy/gostinaya/kresla_3.jpg`, вариант 2) по бокам журнального стола («буквой П»), округлые формы, букле цвета **«тёмный шалфей»** (≈#5F6E5A, диван и кресла одного цвета; `07_referensy/gostinaya/divan_temno_zelenyi_3.jpg`); журнальный стол — овал ~1200×700, белый мрамор с серым, на тёмном основании; **ТВ-зона**: подвесная тумба ~2200×400, **ТВ 85″ (~1900×1070)** в цвет стен (низ ~250 от пола), ТВ на стене в рамке молдинга, провода в стене; **шторы**: тюль + плотные шторы в цвет стен «волной», от потолка до пола, 2-рядный скрытый карниз в нише 150 у окна; **ковёр** — светлый однотонный молочный, короткий ворс (~2,4×3,0, под передние ножки дивана и кресел); **бра — нет** (убраны); **шкаф у двери и ТВ-тумба** — тёплый грейж на тон темнее стен (чтобы не сливались), рамки на фасадах, латунные ручки/кнопки; модели — подобрать |

## 3. Электрика (кратко)

- Розетки: общие h=300; у кровати h=700; рабочий стол h=900; ТВ h=1100 (4 шт + LAN); кухня над столешницей h=1100; стиралка h=1000 IP44; зеркало h=1100 IP44; кондиционеры h=2200; бойлеры h=2000 IP44; насос бака h=1300 IP44.
- Выключатели h=900, 100–150 мм от откоса со стороны ручки; ванная/санузел — снаружи.
- Кабель ВВГнг(А)-LS: 3×2,5 розетки, 3×6 плита (C32), 3×1,5 свет (C10). Влажные зоны — УЗО/дифавтомат 30 мА.
- Щит — прихожая, h=1500. Группы — 13 (см. `album.py`, лист «Щит: группы»).

## 4. Открытые вопросы

1. Реальная глубина кухни и положение её окна (А, Б).
2. Стена Д в спальне 2 — влезет ли шкаф 2180.
3. Положение стояков Т1–Т3 и расстояние до них (уклон слива биде ≥2 %, до ≈7 м).
4. Декор бамбуковых панелей (скрины Dekorchi) и по каким комнатам.
5. Цвет стен гостиной — **РЕШЕНО: светлый тёплый белый** (вариант А, `07_referensy/gostinaya/sravnenie_5_cvetov.jpg`). **Код: NCS S 1002-Y** (≈#E0DCD1, согласовано, `07_referensy/gostinaya/kraska_3_koda.jpg`); колеровка любой маркой (Tikkurila/Dulux/Caparol), моющаяся; перед покупкой — выкрас 50×50 с образцом доски. Яркие цвета заказчику не понравились.

## 5. Ключевые требования заказчика
- Запас воды на случай отключения: бак 200 л + насос + байпас (санузел, у душа).
- Биде: санузел — подвесное биде; ванная — бюджетно (гигиенический душ), выводы под биде оставить.
- Стиральная машина — ванная, угол у двери, бойлер Б1 над ней.
- Стиль: **гостиная — неоклассика**; стиль остальных помещений **НЕ выбран** — подбираем референсы в интернете и согласовываем.
- Порядок работы: дизайн, цвета, текстуры — только после согласования референсов.

## 6. Как устроен проект

```
data/kvartira.json   ← ЕДИНСТВЕННЫЙ источник: стены, окна, двери, помещения (стиль, пол, свет),
                       мебель, розетки, стояки, требования. Правится только он.
core.py              ← загрузка данных, площади, класс листа (рамка, штамп, экспликация)
listy_osnovnye.py    ← листы: мебель, розетки, выключатели, сантехника, узлы, конд., тёплый пол,
                       развертки с/у, ванной, кухни, план кухни, замерный лист
listy_novye.py       ← листы: титул, ведомость, требования, обмер с цепочками, демонтаж/монтаж,
                       мебель с размерами, полы, потолок, свет, план разверток, развертки комнат,
                       ведомость отделки, материалы, визуализации
render.py            ← SVG → PNG и векторный PDF через Chrome/Edge
build.py             ← порядок листов (= ведомость) и сборка альбома
kvartira_blender.py  ← 3D-сцена, читает тот же kvartira.json
_old/                ← прежние версии скриптов (резерв)
```

| Папка | Что |
|---|---|
| `01_chertezhi/` | PNG всех листов (генерируются) |
| `02_skripty/` | скрипты и `data/kvartira.json` |
| `03_materialy/` | Доска материалов (старый черновик; травертин и ламели устарели — актуальное на листе «Материалы») |
| `04_rendery_chernovik/` | Черновые рендеры |
| `05_ishodniki/` | Эскиз замера, старые листы, образец альбома дизайнера |
| `06_albom/` | `albom_chernovik.pdf` — весь альбом одним файлом |

### Как перегенерировать
```
cd 02_skripty
python build.py          # все листы + PDF (≈1,5 мин); нужен Python 3, PyMuPDF, Pillow, Chrome или Edge
python build.py --fast   # только проверить, что всё строится
```
После замера правятся координаты в `data/kvartira.json` (стены `walls`, помещения `rooms[].rects`,
окна, двери, мебель) и у проверенных помещений `"status": "check"` меняется на `"ok"` —
оранжевые «размеры под вопросом» станут обычными красными.
